Завдання 1: Робота з об'єктами

Об'єкт book з властивостями title, author, year, isRead та методом bookInfo.

let book = { title: "Harry Potter and the Sorcerer's Stone", author: "J.K. Rowling", year: 1997, isRead: true };
book.bookInfo = function () { return `Назва: ${this.title}, ...`; };
book.isRead = !book.isRead;

Завдання 2: Масиви та об'єкти

Масив library, функція displayLibrary та додавання книги через push().

function displayLibrary() { library.forEach(book => book.bookInfo()); }
library.push(new Book("The Great Gatsby", "F. Scott Fitzgerald", 1925, false));
